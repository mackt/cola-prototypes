让 Agent 安全地向用户要密钥

现在模型需要 API token、密码时，只能让用户把它贴进聊天框：值会留在对话记录里、发给模型服务商、进日志。新工具 request_secret 改成：在对话里弹一张安全卡片，用户填进卡片。值只进 Cola 的临时密钥存储；模型只拿到「怎么引用它」，命令输出里出现的值会被替换成 [REDACTED:名字]。

    三、各种情况下的行为

    情况 用户看到 模型收到
    用户提供 卡片里填写并提交，卡片收成一行「已保存」 怎么引用它，不含值
    没填卡片，直接打字 卡片收成一行「未提交」，消息照常发出 用户发了消息、没给值，读消息接着聊
    30 分钟没响应 卡片收成一行「未提交」 超时，没有拿到值
    用户点停止 卡片收成一行「未提交」 这一轮被中断
    要长期用（比如配置 MCP） Cola 把值写进对应的配置文件，以后不用再填 只知道变量名，用命令把变量写进配置，不碰明文
    定时任务、后台任务 不会弹卡片，没人在等着回答 不可用，下次用户来时再说明需要什么
    实现：apps/agent-runtime/src/agent/tools/request-secret/ 卡片：apps/desktop/src/renderer/components/SecretRequestBlock.tsx 脱敏扩展：apps/agent-runtime/src/agent/extensions/secret-redactor.ts
